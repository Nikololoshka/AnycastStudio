# Multi-Platform Video Uploader

A Windows desktop client for publishing videos to multiple platforms
(YouTube, X, Instagram, TikTok) from a single interface.

## Stack

- [Tauri](https://tauri.app/) + Rust
- React + TypeScript
- [HeroUI v3](https://heroui.com/) + [Tailwind CSS v4](https://tailwindcss.com/)
- [Redux Toolkit](https://redux-toolkit.js.org/)
- [Motion](https://motion.dev/) for animation, [Lucide](https://lucide.dev/) and
  [Simple Icons](https://simpleicons.org/) for icons

The interface follows the system light/dark setting and can be switched manually
from the top bar.

## Getting Started

```bash
npm install
npm run tauri dev
```
